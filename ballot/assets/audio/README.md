# The recordings

Seventeen files belong in this folder, named exactly as below, as `.mp3`.
They are the things the terminal says that never change.

**Until a file is here, ASSN Ballot speaks the script itself** using the
workstation's own voice. Nothing is ever left unsaid — but a recorded human
voice carries across a hall far better than a synthesised one, so record
them before polling day.

Record them in a quiet room, at a steady pace, with about half a second of
silence at each end. One voice for all seventeen. Say the words as written:
a voter who has heard "Access denied" three times at three terminals should
hear the same sentence each time.

| --- | --- |

| `member_verified.mp3` | Member verified successfully. Welcome to ASSN Ballot. |
| `voter_denied.mp3` | Access denied. Your index number is not registered in the ASSN database. |
| `dues_unpaid.mp3` | Access denied. Dues payment is required to participate in this election. |
| `already_voted.mp3` | Access denied. You have already cast your vote for this election. |

| `election_postponed.mp3` | Notice: The election has been postponed by the Electoral Commission. |
| `election_ended.mp3` | Voting has officially ended. Thank you for your participation. |

## What is deliberately not recorded

Candidates' names, the posts they are standing for, and what a voter has
just chosen. Those come from the database and change with every election,
so no recording could cover them. The terminal speaks them with the
workstation's own voice and — more importantly — writes them in a page a
screen reader reads properly on its own: one `fieldset` per post, one radio
per candidate, the choice read back before anything is submitted.
